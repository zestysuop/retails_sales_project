# Retail Sales Data Analysis Using Python & Pandas

This project focuses on analyzing retail sales data using Python and the Pandas library to extract meaningful business insights and identify sales trends.

The project involves data loading, data cleaning, exploratory data analysis (EDA), data manipulation, and statistical analysis to understand sales performance across different cities, product categories, and payment methods.

### Key Objectives
- Clean and preprocess raw retail sales data.
- Identify and handle missing values and duplicate records.
- Analyze revenue and sales performance across product categories.
- Compare sales across different cities.
- Identify top-performing products.
- Calculate average order value and other key sales metrics.
- Generate actionable insights from the data.

### Tools & Technologies
- Python
- Pandas
- NumPy
- Jupyter Notebook
- Git & GitHub

### Project Outcome
The goal is to transform raw retail sales data into meaningful information through data analysis and develop practical skills in data manipulation, exploratory data analysis, and business problem-solving.

*Note: This project uses a synthetic retail sales dataset created for learning and portfolio development.*
